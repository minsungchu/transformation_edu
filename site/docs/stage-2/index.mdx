# 2단계 · 회전

1단계가 좌표계라는 *언어*였다면, 2단계는 좌표계 사이의 **자세**를 숫자로 적는
첫 계산입니다.

- **배우는 것 다섯 가지**
  - 평면에서 각 하나로 도는 2×2 회전 행렬
  - 3D의 축별 회전 $R_x$, $R_y$, $R_z$
  - 회전의 합성 — 곱이고, 순서가 결과를 바꿈
  - passive와 active — 무엇이 도는가
  - 회전 행렬 읽는 법 — 열 = 축의 방향벡터

## 1. 회전 뷰어

이 단계 전체에서 쓰는 도구입니다. 슬라이더로 좌표계를 돌리면 3×3 행렬이
실시간으로 갱신됩니다.

- **드래그** — 씬을 돌려 여러 각도에서 관찰
- **행렬 열에 마우스** — 그 열이 가리키는 축만 씬에 남음
- **각 절에서** — 이 뷰어를 절에 맞는 구성으로 다시 만남

## 2. 절 구성

다섯 개의 절을 순서대로 읽습니다.

- **[2-1. 2D 회전](./rotation-in-2d.mdx)** — 각 하나, 2×2 행렬, 점이 도는 원리
  - 핵심 질문: 행렬의 열은 어디서 왔나
- **[2-2. 3D 회전](./axis-rotations-in-3d.mdx)** — 축별 회전 $R_x$, $R_y$, $R_z$와 3×3 행렬
  - 핵심 질문: 3D에서는 왜 축을 먼저 골라야 하나
- **[2-3. 합성과 순서](./composing-rotations.mdx)** — 회전은 곱, 순서가 결과를 바꿈
  - 핵심 질문: $R_z R_x$와 $R_x R_z$는 왜 다른가
- **[2-4. Euler와 RPY](./euler-and-rpy.mdx)** — passive와 active, 이 교재는 passive로 통일
  - 핵심 질문: 같은 세 숫자가 왜 장비마다 다른 자세가 되나
- **[2-5. 회전 행렬 읽기](./reading-a-rotation-matrix.mdx)** — 열 = 방향벡터, orthonormal, $R^{T} = R^{-1}$
  - 마무리: 2단계 이해 확인 퀴즈
