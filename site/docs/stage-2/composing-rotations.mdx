# 2-3. 합성과 순서

## 1. 회전을 잇는 것은 곱이다

- **두 번 돌기** — $A$에서 본 $B$, $B$에서 본 $C$를 알면 $A$에서 본 $C$를 얻음
  - 식: $R^{A}_{C} = R^{A}_{B} \cdot R^{B}_{C}$
  - 소거: 인접한 $B$가 사라짐 — 1-4절의 체인룰과 같은 규칙
- **읽는 방향** — 오른쪽 행렬이 먼저 일어난 회전
  - 이유: 점에 곱해질 때 오른쪽부터 닿음
- **결과도 회전** — 회전 행렬끼리 곱하면 다시 회전 행렬

## 2. 순서가 결과를 바꾼다

행렬 곱은 교환법칙이 성립하지 않습니다. 회전에서도 마찬가지입니다.

$$
R_z(90^\circ)\,R_x(90^\circ) \;\neq\; R_x(90^\circ)\,R_z(90^\circ)
$$

- **비가환** — 같은 두 회전을 순서만 바꿔도 다른 자세
  - 손으로 확인: 책을 눕혔다 세우기 / 세웠다 눕히기
- **예외** — 회전축이 같으면 순서를 바꿔도 같음
  - 예: $R_z(30^\circ) R_z(40^\circ) = R_z(70^\circ)$
- **실무에서 뜻하는 것** — "$x$로 90, $z$로 90" 이라는 말만으로는 자세가 정해지지 않음
  - 반드시 필요한 것: 순서 + 회전 기준(2-4절)

:::caution[순서를 빼먹으면 자세가 정해지지 않습니다]

각 세 개를 주고받을 때는 **회전 순서**를 함께 명시해야 합니다. 장비·라이브러리마다
기본 순서가 달라서, 같은 숫자 세 개가 서로 다른 자세로 해석되는 것이 현장에서 가장
흔한 자세 오류입니다.

- 최소 조건: 축 순서(예: ZYX) + 회전 기준(passive / active)

:::

## 3. 뷰어로 비교

같은 세 회전을 순서만 뒤집어 나란히 그립니다. **▶ 순서대로 돌려보기**를 누르면 한
단계씩 도는 과정이 보입니다.

- **초기 설정** — $R_z(90^\circ) R_x(90^\circ)$ 대 $R_x(90^\circ) R_z(90^\circ)$
  - 화면: 진한 축이 앞의 것, 짧고 흐린 "순서 바꿈" 축이 뒤의 것
- **관찰 1 — 두 좌표계가 어긋남** — 배지에 "두 행렬이 다르다"
- **관찰 2 — $R_y$만 남기고 나머지 0** — 한 축 회전만 남으면 두 결과가 겹침
  - 배지: "가환"으로 바뀜
- **관찰 3 — order 바꾸기** — 축 순서를 고르면 같은 각도라도 다른 자세

## 4. 정리

- **합성** — $R^{A}_{C} = R^{A}_{B} R^{B}_{C}$, 오른쪽이 먼저
- **비가환** — 순서를 바꾸면 다른 자세 (축이 같을 때만 예외)
- **각 세 개** — 순서를 함께 적어야 자세가 확정됨

다음 절에서는 남은 조건인 **회전 기준**을 정리합니다.
