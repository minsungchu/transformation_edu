# 2단계 · Transformation Matrix (가제)

## 예정 내용

- 4×4 Transformation Matrix의 구성 (회전 + 이동)
- 좌표 표현의 변환: $P^{A} = T^{A}_{B} \cdot P^{B}$
- 체인룰과 인접 인덱스 소거: $T^{A}_{C} = T^{A}_{B} \cdot T^{B}_{C}$
- 역변환: $T^{B}_{A} = (T^{A}_{B})^{-1}$
- 회전각 표현 — passive Euler (active RPY는 개념 비교로만)
