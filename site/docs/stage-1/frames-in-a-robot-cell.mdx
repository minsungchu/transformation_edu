# 1-2. 로봇 셀의 좌표계들

로봇 셀에는 좌표계가 하나가 아닙니다. 장비마다 자기 좌표계가 붙어 있고, 그중 어떤
것은 바닥에 고정되어 있고 어떤 것은 로봇을 따라 움직입니다. 이 절에서는 이 교재에
계속 등장할 좌표계 다섯 개를 하나씩 "어디에 붙어 있는지"로 익힙니다.

## World 좌표계 — 모든 것의 기준

**World 좌표계**는 로봇의 **Base**(로봇 첫 번째 축이 시작되는 바닥 부분)를 원점으로
하는 좌표계입니다. 셀 안에서 움직이지 않는 기준이며, 로봇에게 내리는 위치 명령은
결국 모두 이 좌표계 기준으로 표현됩니다.

:::info[용어 주석 — World vs Robot Base]

일반 로보틱스 문헌은 **World 좌표계**(셀 전체의 기준)와 **Robot Base 좌표계**(로봇
받침 기준)를 구분하기도 합니다. 로봇이 여러 대이거나 셀 기준점이 따로 있으면 둘이
다를 수 있기 때문입니다. 이 교재는 사내 규칙에 따라 로봇 Base 기준 좌표계를 그냥
**World 좌표계**로 통일해 부릅니다 — Robot 좌표계, Base 좌표계라는 이름은 쓰지
않습니다. 외부 자료를 읽을 때 "base frame"이 이 교재의 World 좌표계에 해당한다는
것만 기억해 두세요.

:::

## Flange 좌표계 — 로봇 손목 끝

**Flange**는 로봇의 마지막 축 끝에 있는 금속 원판입니다 — 그리퍼든 카메라든, 공구는
전부 여기에 볼트로 붙습니다. **Flange 좌표계**는 이 원판 중심을 원점으로 하며,
로봇이 움직이면 함께 움직입니다. "로봇이 지금 어디를 향해 있나"를 말할 때 로봇
제어기가 실제로 계산해 내는 것이 이 좌표계의 pose입니다.

## Tool 좌표계 — 공구 끝점 (TCP)

Flange에 그리퍼나 용접 토치를 달면, 실제로 일하는 지점은 flange가 아니라 **공구의
끝**(tooltip)입니다. 이 끝점이 **TCP**(Tool Center Point)이고, TCP를 원점으로 하는
좌표계가 **Tool 좌표계**입니다.

- 공구를 달지 않았다면 Tool 좌표계는 Flange 좌표계와 사실상 같은 곳에 있습니다.
- 공구를 바꾸면 Flange는 그대로지만 **TCP는 바뀝니다** — 그래서 둘을 구분합니다.

## Camera 좌표계 — 센서의 눈

**Camera 좌표계**는 카메라(Sensor)를 기준으로 하는 좌표계입니다. 카메라가 찍은 모든
점의 위치는 처음에는 오직 이 좌표계 기준으로만 얻어집니다 — 카메라는 World 좌표계를
전혀 모릅니다. 이 간극을 잇는 것이 나중에 배울 calibration입니다.

:::info[용어 주석 — Sensor / Scene 좌표계라고도 불립니다]

자료에 따라 같은 좌표계를 Sensor 좌표계, Scene 좌표계라고 부르기도 합니다. 이
교재는 전부 **Camera 좌표계**로 통일합니다.

:::

## User 좌표계 — 사용자가 정의하는 기준

**User 좌표계**는 작업대나 지그(jig) 같은 작업 환경에 사용자가 직접 정의해 붙이는
좌표계입니다. "작업대 모서리를 원점으로, 작업대 긴 변을 x축으로" 같은 식입니다.
나중에 조그(jog)를 배울 때, 로봇을 움직이는 기준 좌표계 선택지(world / tcp / user)
중 하나로 등장합니다. 아래 뷰어의 작업대에 붙은 좌표계가 그 예라고 생각하면 됩니다.

## 정리 — 다섯 좌표계 한눈에

| 좌표계 | 원점 | 붙는 곳 | 로봇이 움직이면? |
| :-- | :-- | :-- | :-- |
| **World** | 로봇 Base | 바닥 (고정) | 고정 |
| **Flange** | 마지막 축 끝 원판 중심 | 로봇 손목 | **함께 움직임** |
| **Tool** | TCP (공구 끝점) | 공구 | **함께 움직임** |
| **Camera** | 카메라 (Sensor) | 설치 방식에 따라 다름 | 다음 절(1-3)에서! |
| **User** | 사용자 정의 | 작업대·지그 | 고정 |

Camera 좌표계의 "설치 방식에 따라 다름"이 바로 다음 절의 주제, **Mount 두 방식**
입니다.
