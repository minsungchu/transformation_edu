# 1-2. 로봇 셀의 좌표계들

로봇 셀에는 좌표계가 하나가 아닙니다. 이 절에서는 이 교재에 계속 등장할 좌표계
다섯 개를 하나씩 "어디에 붙어 있는지"로 익힙니다.

## World 좌표계 — 모든 것의 기준

**World 좌표계**는 셀 안에서 움직이지 않는, 모든 것의 기준입니다.

- **원점** — 로봇의 **Base**
  - Base: 로봇 첫 번째 축이 시작되는 바닥 부분
- **움직임** — 셀에 고정
- **역할** — 로봇에게 내리는 모든 위치 명령의 최종 기준

:::info[용어 주석 — World vs Robot Base]

일반 로보틱스 문헌은 **World 좌표계**와 **Robot Base 좌표계**를 구분하기도 합니다.
로봇이 여러 대이거나 셀 기준점이 따로 있으면 둘이 다를 수 있기 때문입니다.
이 교재는 사내 규칙에 따라 로봇 Base 기준 좌표계를 **World 좌표계**로 통일해
부릅니다.

- 쓰지 않는 이름: Robot 좌표계, Base 좌표계
- 외부 자료의 "base frame": 이 교재의 World 좌표계에 해당

:::

## Flange 좌표계 — 로봇 손목 끝

**Flange**는 로봇의 마지막 축 끝에 있는 금속 원판입니다. 그리퍼든 카메라든, 공구는
전부 여기에 볼트로 붙습니다.

- **원점** — 원판 중심
- **움직임** — 로봇이 움직이면 함께 움직임
- **역할** — "로봇이 지금 어디를 향해 있나"의 실체
  - 로봇 제어기가 실제로 계산해 내는 것: 이 좌표계의 pose

## Tool 좌표계 — 공구 끝점

Flange에 그리퍼나 용접 토치를 달면, 실제로 일하는 지점은 flange가 아니라 공구의
끝입니다.

- **TCP(Tool Center Point)** — 공구 끝점
- **원점** — TCP
- **Flange와 구분하는 이유** — 공구를 바꾸면 Flange는 그대로지만 TCP는 바뀜
  - 공구가 없을 때: Tool 좌표계는 Flange 좌표계와 사실상 같은 곳

## Camera 좌표계 — 센서의 눈

**Camera 좌표계**는 카메라(Sensor)를 기준으로 하는 좌표계입니다.

- **역할** — 카메라가 찍은 모든 점이 처음 얻어지는 유일한 기준
- **한계** — 카메라는 World 좌표계를 전혀 모름
  - 이 간극을 잇는 것: 나중에 배울 calibration
- **다른 이름** — 자료에 따라 Sensor 좌표계, Scene 좌표계
  - 이 교재: 전부 **Camera 좌표계**로 통일

## User 좌표계 — 사용자가 정의하는 기준

**User 좌표계**는 작업 환경에 사용자가 직접 정의해 붙이는 좌표계입니다.

- **붙는 곳** — 작업대, 지그 등
- **정의 예** — 작업대 모서리를 원점으로, 작업대 긴 변을 x축으로
- **다시 만나는 곳** — 조그(jog)의 기준 좌표계 선택지 world / tcp / user 중 하나
- **뷰어에서** — 작업대에 붙은 좌표계가 그 예

- **World** — 로봇 발밑, 셀에서 가장 큰 축, 고정
- **Flange** — 로봇 손목 끝 원판
  - 관찰법: Tool과 거의 겹쳐 있으니 번갈아 켜 보기
- **Tool** — TCP 위치
  - 이 로봇: 공구가 없어서 flange 바로 옆
- **Camera** — 작업대 위 카메라
  - 관찰 포인트: 파란 z축, 즉 광축이 작업대를 내려다봄

## 정리 — 다섯 좌표계 한눈에

| 좌표계     | 원점                   | 로봇이 움직이면?     |
| :--------- | :--------------------- | :------------------- |
| **World**  | 로봇 Base              | 고정                 |
| **Flange** | 마지막 축 끝 원판 중심 | **함께 움직임**      |
| **Tool**   | TCP                    | **함께 움직임**      |
| **Camera** | 카메라                 | 설치 방식에 따라 다름 |
| **User**   | 사용자 정의            | 고정                 |

Camera 좌표계의 "설치 방식에 따라 다름"이 바로 다음 절의 주제, **Mount 두 방식**
입니다.
