# 1단계 · 좌표계 기초

1단계에서는 이후 모든 챕터의 전제가 되는 "좌표계라는 언어"를 익힙니다.
**계산은 아직 하지 않습니다** — 언어를 먼저 익히고, 수학은 2단계에서 시작합니다.

- **배우는 것 네 가지**
  - 좌표계라는 개념
  - 로봇 셀에 붙어 있는 좌표계들
  - 카메라 설치 방식 두 가지 — Mount
  - 좌표계 관계의 표기법 $T^{A}_{B}$와 화살표 도식 읽는 법
