# 1단계 · 좌표계 기초

1단계에서는 이후 모든 챕터의 전제가 되는 네 가지를 배웁니다 — 좌표계라는 개념,
로봇 셀에 붙어 있는 좌표계들, 카메라 설치 방식(Mount) 두 가지, 그리고 좌표계 관계를
적는 표기법 $T^{A}_{B}$와 화살표 도식을 읽는 법. **계산은 아직 하지 않습니다** —
언어를 먼저 익히고, 수학은 2단계에서 시작합니다.

## 이 단계에서 다루는 로봇 셀

로봇(UR5e), 작업대, 그리고 카메라로 이루어진 셀입니다. 마우스로 드래그해 셀을
돌려보고, 아래 토글로 좌표계 축(RGB 화살표), Post ↔ Robot Mount 전환, 좌표계 사이의
$T$ 화살표(꼬리 = 기준, 화살촉 = 타겟)를 켜 보세요. 각 절에서 이 뷰어를 절에 맞는
구성으로 다시 만납니다.
