# 1단계 · 로봇 용어와 좌표계

로봇을 다루려면 먼저 **로봇 위의 세 지점**과 거기에 붙은 좌표계를 알아야 합니다.
그다음 그 좌표계를 기준으로 로봇을 직접 움직여 봅니다.

- **배우는 것 세 가지**
  - 로봇 용어 — 로봇 베이스, 플랜지, TCP
  - 각 지점에 붙은 좌표계 — World(Base), Flange, Tool(TCP)
  - 조깅 — Joint / Base / TCP / Flange / User 기준으로 로봇 움직이기
