# 1-4. 표기법과 화살표 도식 읽기

:::caution[미작성 챕터]

이 챕터는 아직 작성되지 않았습니다.

:::

## 예정 내용

- $T^{A}_{B}$ 표기 읽는 법 — 위첨자 = 기준(reference) 좌표계, 아래첨자 = 타겟
- 점 표기 $P^{A}_{name}$ — 위첨자 = 표현 좌표계, 아래첨자 = 점의 이름
- from-to 화살표 도식 — 꼬리 = 기준 좌표계 원점, 화살촉 = 타겟 좌표계 원점
