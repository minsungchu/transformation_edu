# 1-1. 좌표계란 무엇인가

## 1. 위치는 항상 "어디 기준"인가

비전 시스템이 로봇에게 이렇게 알려 줬다고 합시다.

> "부품이 $(120,\ 45,\ 380)$ 위치에 있습니다. (단위: mm)"

로봇은 이 숫자만 듣고 부품을 집으러 갈 수 있을까요? **갈 수 없습니다.**

- **숫자만으로 부족한 이유** — "어디를 기준으로 잰 값인지"가 없으면 세 숫자는 무의미
  - 기준 후보: 카메라 렌즈, 로봇 발밑, 작업대 모서리
  - 결과: 기준마다 로봇이 가야 할 곳이 완전히 달라짐
- **위치의 본질** — 절대적인 값이 아니라, 언제나 "어떤 기준에서 본 값"
- **좌표계** — 이 "기준"을 수학적으로 정확하게 만든 것
- **로봇 응용 사고의 대부분** — 숫자가 틀려서가 아니라, 같은 숫자를 서로 다른 기준으로 해석해서 발생
  - 그래서: 이 교재 전체가 좌표계 이야기

## 2. 좌표계 = 원점 + 세 축

좌표계는 딱 두 가지로 정의됩니다.

- **원점** — 기준점
  - 의미: "여기서부터 잰다"의 *여기*
- **세 축 x, y, z** — 서로 직교하는 세 방향
  - 의미: "어느 쪽으로 얼마나"의 *어느 쪽*
- **정의가 주는 것**
  - 원점과 세 축이 정해지면: 공간의 모든 점을 세 숫자로 표현 가능
  - 뒤집어 말하면: 세 숫자는 좌표계가 정해져야만 위치가 됨

이 교재의 3D 뷰어에서 좌표계 축은 항상 같은 색으로 그립니다.

| 축  | 색      |
| :-- | :------ |
| x축 | 🔴 빨강 |
| y축 | 🟢 초록 |
| z축 | 🔵 파랑 |

- **기억법** — RGB 순서 = xyz 순서
- **통용 범위** — ROS, 각종 시뮬레이터 등 로보틱스 도구 전반

## 3. 오른손 법칙

세 축의 *방향*은 마음대로 정하지 않습니다. x축과 y축이 정해지면 z축은
**오른손 법칙**으로 정해집니다.

- **손가락 대응**
  - 검지: x축 방향
  - 중지: y축 방향으로 구부림
  - 엄지: z축 방향
- **한 줄 요약** — x축을 y축 쪽으로 감아쥘 때 엄지가 z축
- **오른손 좌표계** — 이 규칙을 따르는 좌표계
  - 적용 범위: 로보틱스의 좌표계 전부

빨강 x축을 초록 y축 쪽으로 감아쥐면 엄지가 파랑 z축, 즉 위를 향합니다.

- **뷰어 조작** — 드래그로 씬을 돌려, 축 세 개가 만나는 원점을 여러 각도에서 관찰
  - 관찰 포인트: 어느 각도에서 봐도 축의 직교 관계와 오른손 법칙은 불변

## 4. 정리

- **위치 세 숫자** — 기준이 되는 좌표계가 정해져야만 의미가 있음
- **좌표계** — 원점 + 서로 직교하는 세 축
  - 축 색: RGB = xyz
- **세 축의 방향** — 오른손 법칙
