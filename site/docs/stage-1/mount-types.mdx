# 1-3. Mount 두 방식

카메라를 셀 어디에 설치하느냐에는 두 가지 방식이 있습니다. 이 선택이 이후 배울
calibration의 종류까지 결정합니다.

## 1. Post Mount — 고정 구조물에 부착

**Post Mount**는 카메라를 기둥이나 프레임 같은 **고정 구조물**에 설치하는
방식입니다.

- **Camera 좌표계** — 셀에 고정
  - 로봇이 어떻게 움직여도: 카메라는 그대로
- **변하지 않는 관계** — World ↔ Camera
  - 의미: 한 번 calibration으로 알아내면, 로봇이 일하는 내내 그대로 사용
- **시야** — 고정
  - 특징: 항상 같은 영역을 봄

## 2. Robot Mount — 로봇에 부착

**Robot Mount**는 카메라를 로봇의 **Flange 쪽에** 직접 다는 방식입니다.
"hand-eye" 구성이라고도 부릅니다.

- **Camera 좌표계** — 로봇을 따라 움직임
  - 로봇 자세가 바뀔 때마다: World 기준 카메라의 위치·방향이 달라짐
- **변하지 않는 관계** — Flange ↔ Camera
  - 이유: 둘 다 같은 손목에 볼트로 붙어 있음
  - 이 관계를 알아내는 것: 나중에 배울 hand-eye calibration
- **시야** — 로봇이 카메라를 들고 다님
  - 장점: 원하는 곳에 가까이 가서 촬영 가능

## 3. 뷰어로 확인하기

아래 뷰어에서 **Mount 토글을 Post ↔ Robot으로 전환**해 보세요. Camera 축과 Flange
축을 켠 채로 관찰하세요.

- **Post일 때** — 카메라는 공중의 고정 위치
  - Camera 좌표계: 로봇과 무관하게 셀에 고정
- **Robot일 때** — 카메라가 로봇 손목 옆에 부착
  - 관찰 포인트: Camera 축이 Flange 축과 나란히 *한 몸으로* 붙어 있음
  - $T$ 화살표 Flange → Camera: 두 좌표계를 잇는 짧은 화살표 — 로봇이 어떤 자세를 취해도 불변

## 4. 비교 정리

|                    | Post Mount     | Robot Mount             |
| :----------------- | :------------- | :---------------------- |
| 카메라 설치 위치   | 고정 구조물    | 로봇 Flange 쪽          |
| Camera 좌표계      | 셀에 고정      | **로봇 따라 움직임**    |
| 변하지 않는 관계   | World ↔ Camera | **Flange ↔ Camera**     |
| 시야               | 고정           | 로봇이 옮겨 다니며 촬영 |
| 관련 calibration   | w2s            | f2s, hand-eye           |

:::note[w2s / f2s?]

w2s와 f2s는 calibration 관계를 가리키는 **의미적 명칭**입니다. 수식 표기가
아니므로 지금은 이름만 알아 두면 충분합니다.

- w2s: World-To-Scene — 3단계 Calibration에서 다룸
- f2s: Flange-To-Scene — 5단계 Hand-Eye에서 다룸

:::

어느 방식이든 결국 필요한 것은 같습니다 — "**카메라가 본 것**을 **로봇의 기준**으로
옮기는 다리". 그 다리를 정확하게 적는 언어가 다음 절의 주제입니다.
